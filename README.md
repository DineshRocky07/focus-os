## 🚀 How to Run FocusOS

FocusOS is designed to be **instant, free, and zero-lag**:
1. Simply double-click **`index.html`** in this folder to open it in Google Chrome, Microsoft Edge, or Brave.
2. Or run a local live server:
   ```powershell
   # If you have python installed:
   python -m http.server 3000
   ```
   Then open `http://localhost:3000`.

---

## 🔑 Dual Google Gemini API Setup (Account 1 & Account 2)
You mentioned having two Google accounts with free Gemini API keys:
1. Click the **"Gemini Dual Keys"** button in the top right header.
2. Paste **Key 1** (Google Account 1) and **Key 2** (Google Account 2).
3. If Key 1 reaches its free quota or rate limit, FocusOS will **automatically failover to Key 2** seamlessly!
4. *Note: Keys are stored exclusively in your browser's private `localStorage` and never sent anywhere except directly to Google's official Gemini endpoint.*
